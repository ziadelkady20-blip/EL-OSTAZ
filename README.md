# الأستاذ – منصة الطباعة والخدمات

منصة عربية RTL لطلبات الطباعة، بهوية الأستاذ الرسمية.

## المكونات
- واجهة العميل: اختيار خدمة الطباعة، نوع الورق، المقاس، التشطيب، عدد النسخ، وإرفاق ملف.
- Backend على Vercel Functions.
- PostgreSQL على Neon لتخزين الطلبات وحالاتها وسجل التحديثات.
- Vercel Blob Private لتخزين ملفات الطباعة بعيدًا عن الروابط العامة.
- لوحة إدارة محمية بتسجيل دخول لتحديث حالة الطلب والسعر وإضافة رسالة للعميل.
- صفحة عامة لتتبع الطلب باستخدام رقم فريد غير قابل للتخمين عمليًا.

## تشغيل المشروع
يتطلب Node.js 22+، ثم:
`npm install`

## متغيرات البيئة
- `DATABASE_URL`: اتصال Neon PostgreSQL.
- `BLOB_READ_WRITE_TOKEN`: رمز Vercel Blob Private Store.
- `ADMIN_USERNAME`: اسم مستخدم الإدارة.
- `ADMIN_PASSWORD`: كلمة مرور الإدارة.
- `ADMIN_SESSION_SECRET`: مفتاح توقيع جلسات الإدارة.

## API
- `POST /api/orders`: إنشاء طلب ورفع ملفه إلى Blob Private.
- `GET /api/orders`: قائمة الطلبات (للمدير فقط).
- `POST /api/orders/status`: تحديث حالة الطلب والسعر ورسالة العميل (للمدير فقط).
- `GET /api/orders/file?id=...`: تنزيل ملف خاص (للمدير فقط).
- `GET /api/track?code=...`: تتبع حالة طلب عبر رقم الطلب.
- `POST /api/admin/login`, `GET /api/admin/me`, `POST /api/admin/logout`: جلسة الإدارة.
- `GET /api/health`: فحص اتصال قاعدة البيانات.

## حدود النسخة الحالية
- الحد الأقصى لملف الطلب 3 ميجابايت بسبب حد جسم طلب Vercel Functions؛ ملفات الطباعة الأكبر تحتاج مسار رفع متعدد الأجزاء/مباشر إلى تخزين خاص.
- الدخول الحالي حساب مدير واحد من متغيرات البيئة؛ إدارة الموظفين وتغيير كلمة المرور من داخل لوحة الإدارة مرحلة لاحقة.
- لا يتم عرض بيانات العميل الشخصية في صفحة التتبع العامة.
- يجب اختبار إعدادات Blob الخاصة على نشر Preview قبل تفعيل استقبال طلبات الإنتاج.

## قاعدة البيانات
تستخدم الجداول الموجودة `print_orders` و`print_settings` دون حذفها أو إعادة إنشائها. ملف `migrations/001_order_indexes.sql` يحتوي فهارس إضافية آمنة فقط.
