# الأستاذ – منصة الطباعة والخدمات

منصة عربية باتجاه RTL بهوية الأستاذ الرسمية (الأزرق الملكي والأبيض)، وتشمل:
- واجهة عميل لاختيار خدمات الطباعة وإدخال تفاصيل الطلب.
- نموذج لاختيار الورق والمقاس والتقفيل وعدد النسخ وإرفاق ملف.
- لوحة إدارة تجريبية لعرض الطلبات وتحديث حالتها.
- تصميم متجاوب للهواتف والحواسيب مع تحسينات وصول أساسية.
- الشعار الرسمي محفوظ في `assets/ostaz-logo.svg`.

## التشغيل
افتح `index.html` مباشرة أو انشر المستودع على Vercel.

## حالة التشغيل الحالية
هذه النسخة ما زالت نموذج واجهات أوليًا:
- الطلبات تُحفظ في `localStorage` داخل المتصفح فقط.
- ملف العميل لا يُرفع إلى خادم ولا يُخزّن في Blob حتى الآن.
- لوحة الإدارة غير محمية بتسجيل دخول أو صلاحيات.
- متغيرات اتصال قاعدة البيانات والتخزين وحدها لا تعني أن التطبيق أصبح يستخدمهما.

يلزم استكمال API وربط قاعدة بيانات Neon وتخزين ملفات آمن ونظام دخول وصلاحيات، ثم اختبار دورة الطلب كاملة، قبل استقبال طلبات عملاء حقيقية.

العلامة التجارية المعتمدة: **الأستاذ**.
