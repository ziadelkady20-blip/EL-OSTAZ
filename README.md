# الأستاذ – منصة الطباعة والخدمات

واجهة عربية RTL أولية تشمل:
- واجهة عميل لاختيار خدمة الطباعة ورفع ملف وتسجيل بيانات الطلب.
- لوحة إدارة لعرض الطلبات وتغيير حالتها.
- تصميم متجاوب للهواتف والحواسيب.

## التشغيل
افتح `index.html` مباشرة أو انشر المستودع على استضافة صفحات ثابتة.

## مهم قبل التشغيل الفعلي
هذه نسخة واجهات ونموذج تفاعلي أولي. الطلبات تحفظ في `localStorage` داخل المتصفح فقط، والملف المرفوع لا ينتقل إلى المطبعة ولا يُخزّن على خادم. لوحة الإدارة غير محمية بتسجيل دخول. يلزم ربط قاعدة بيانات وتخزين ملفات آمن ونظام صلاحيات وخادم لاستقبال الطلبات قبل استقبال عملاء حقيقيين.

العلامة التجارية المعتمدة: **الأستاذ**.
