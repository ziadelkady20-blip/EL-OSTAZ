# الأستاذ – منصة الطباعة والخدمات

منصة عربية RTL لطلبات الطباعة ومتجر الأدوات المدرسية، بهوية الأستاذ الرسمية.

## المكونات
- واجهة العميل: طلب طباعة متعدد الملفات مع حساب تفصيلي للورق والنسخ والتشطيب.
- متجر عام للأدوات المدرسية بأقسام ومنتجات قابلة للإدارة من لوحة التحكم.
- سلة موحدة تجمع ملفات الطباعة ومنتجات المتجر في طلب واحد مع رقم تتبع واحد.
- Backend على Vercel Functions.
- PostgreSQL على Neon لتخزين الطلبات وحالاتها وسجل التحديثات.
- Vercel Blob Private لتخزين ملفات الطباعة بعيدًا عن الروابط العامة.
- لوحة إدارة محمية بتسجيل دخول لتحديث حالة الطلب والسعر وإضافة رسالة للعميل.
- صفحة عامة لتتبع الطلب باستخدام رقم فريد غير قابل للتخمين عمليًا.

## تشغيل المشروع
يتطلب Node.js 22+، ثم:
`npm install`

## متغيرات البيئة
- `DATABASE_URL`: اتصال Neon PostgreSQL.
- `BLOB_READ_WRITE_TOKEN`: رمز Vercel Blob Private Store.
- `ADMIN_USERNAME`: اسم مستخدم الإدارة.
- `ADMIN_PASSWORD`: كلمة مرور الإدارة.
- `ADMIN_SESSION_SECRET`: مفتاح توقيع جلسات الإدارة.

## API
- `POST /api/uploads`: إصدار رمز رفع آمن للمتصفح ورفع مباشر مجزأ إلى Blob Private.
- `POST /api/orders`: إنشاء الطلب وربطه بالملف المرفوع مسبقًا إلى Blob Private.
- `GET /api/orders`: قائمة الطلبات (للمدير فقط).
- `POST /api/orders/status`: تحديث حالة الطلب والسعر ورسالة العميل (للمدير فقط).
- `GET /api/orders/file?id=...`: تنزيل ملف خاص (للمدير فقط).
- `GET /api/track?code=...`: تتبع حالة طلب الطباعة ومشتريات المتجر عبر رقم الطلب.
- `GET /api/orders?catalog=public`: عرض الأقسام والمنتجات في المتجر.
- `GET/POST/PATCH /api/orders?catalog=admin`: إدارة الأقسام والمنتجات (للمدير فقط).
- `POST /api/admin/login`, `GET /api/admin/me`, `POST /api/admin/logout`: جلسة الإدارة.
- `GET /api/health`: فحص اتصال قاعدة البيانات.

## حدود النسخة الحالية
- رفع الملفات يتم مباشرة من متصفح العميل إلى Vercel Blob باستخدام multipart، متجاوزًا حد جسم Vercel Functions البالغ 4.5 ميجابايت. الحد الأقصى التقني للملف الواحد 5 تيرابايت وفق حدود Vercel Blob؛ هذا ليس بلا حدود حرفيًا. الملفات الكبيرة جدًا قد تتأثر بسرعة الإنترنت وحصة التخزين والتكلفة.
- الدخول الحالي حساب مدير واحد من متغيرات البيئة؛ إدارة الموظفين وتغيير كلمة المرور من داخل لوحة الإدارة مرحلة لاحقة.
- لا يتم عرض بيانات العميل الشخصية في صفحة التتبع العامة.
- يجب اختبار إعدادات Blob الخاصة على نشر Preview قبل تفعيل استقبال طلبات الإنتاج.

## قاعدة البيانات
تستخدم المنصة جدول الطلبات الحالي `print_orders` دون حذفه أو إعادة إنشائه. إضافة المتجر تستخدم `catalog_categories` و`catalog_products`، وتضيف حقول JSONB وإجماليات مشتريات المتجر إلى الطلب نفسه حتى تظل الطباعة والمتجر في رقم طلب واحد. ملف `migrations/20261112_add_shared_store.sql` يوثق الإضافة.
